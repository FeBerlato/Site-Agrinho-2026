# Site-Agrinho-2026
Tema Agrinho: "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente".
Para utilizar, abra o site e utilize o scroll do mouse para rolar a página e o botão esquerdo para selecionar as opções na página.
O site foi criado utilizando HTML e javascript, tudo foi feito a partir do Vscode.
O agronegócio brasileiro é fundamental para a economia do país, sendo responsável por alimentar milhões de pessoas no Brasil e no mundo. Porém, é essencial que a produção agrícola caminhe junto com a preservação ambiental.
O projeto tem o objetivo de informar sobre práticas de como podemos preservar a natureza para mantermos e até evoluirmos a qualidade do agro nos dias de hoje, ou seja, como é possível ter um agro forte e ao mesmo tempo um futuro sustentável, com práticas que respeitam o meio ambiente.
